# Quiz : quelle province canadienne est faite pour vous ?

A 20-question quiz in French for francophones (Europe/Africa) coming from social media. It recommends one of the 13 Canadian provinces and territories, then offers three calls to action: book an appointment, buy an audit, buy the ebook.

Plain HTML/CSS/JS with no framework. Every push to `main` uploads it to the GoDaddy hosting (`.github/workflows/deploy-godaddy.yml`).
Test URL: https://quiz.kallistesoft.ca (`noindex` and `robots.txt` block search engines).

## Structure
- `index.html`, `p/<slug>/`, `credits/`: generated by `node tools/build_pages.mjs`. Don't edit them by hand.
- **After editing any file in `css/` or `js/`, run `node tools/build_pages.mjs`.** It adds a content hash (`?v=…`) to every css/js link, so browsers never mix old and new files (otherwise browsers can keep old copies cached).
- `question/`: one page per question (`?q=4&a=021`). Each answer is a real page load, so ads count one view per question.
- `resultat/`: result page (`?a=<20 answers>`).
- `js/config.js`: site URL, button links, AdSense IDs. **This is the only file to edit when moving the quiz.**
- `js/data.js`: provinces, questions and answer weights. `resultMap` shows the territories (Yukon, NWT, Nunavut) as Alberta.
- `js/score.js`: scoring.
- `img/`: Wikimedia Commons photos (licences in `img/credits.json`, shown on `/credits/`).

## Checks
    node tools/check_scoring.mjs   # every province can win, none wins too often

## Moving to the lawyer's domain
1. In `js/config.js`, set `SITE_URL` (and the AdSense IDs). Button links are in the same file: `BOOKING_URL`, `AUDIT_URL`, and `EBOOK_URLS` (per province, so the ebook button only shows for those provinces).
2. Run `node tools/build_pages.mjs`.
3. Remove `noindex` from the pages (`tools/build_pages.mjs`, `question/`, `resultat/`) and replace `robots.txt` if the quiz should be indexed.
4. Change the `folder` in `.github/workflows/deploy-godaddy.yml` to the new domain's folder on the hosting.
5. Before turning ads on: add a Google-certified cookie-consent banner (required for European visitors).

The immigration notes in `js/data.js` were checked in October 2026. Programs change often, so re-check them before each campaign.
